# SATURDAY — website starter

Responsive bilingual (Spanish / English) static website for a digital studio offering AI ad videos, websites, app concepts, branding and AI automation.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design and visual styles
- `script.js` — language toggle, pricing rendering, mobile navigation and project form
- `config.js` — editable prices and contact email
- `assets/saturday-mark.svg` — brand mark

## Run locally
The site is static and does not require a build step.
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a more realistic local test, run a simple static server from this folder:
- Python: `python -m http.server 8000`
- Then visit `http://localhost:8000`

## Before publishing
1. Open `config.js`.
2. Replace `replace-with-your-email@example.com` with an inbox you control.
3. Review the ARS starting prices in `config.js`. They are placeholders, not market-verified quotes. Confirm your costs and scope before offering them to customers.
4. Review all service descriptions, delivery promises and sample work.
5. Publish the folder using a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.

## Contact form limitation
The current form validates required fields and opens the visitor's email app with a prefilled message (`mailto:`). It does not submit information to a server, save leads, or send email by itself. To receive submissions directly on a website, connect a form backend/service or build a server endpoint and add an appropriate privacy notice.

## Important notes
- Portfolio cards are conceptual mockups, not real client work.
- Domain registration, hosting, paid AI services, payment processing, analytics and other third-party services may have costs.
- This is a starter website, not a checkout or customer account platform.
